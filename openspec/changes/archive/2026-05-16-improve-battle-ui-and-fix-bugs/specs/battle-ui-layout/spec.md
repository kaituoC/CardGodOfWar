## ADDED Requirements

### Requirement: 顶部状态栏居中精简
顶部状态栏内容 MUST 居中显示，仅包含关卡号和回合数。怪兽元素信息移至怪兽面板内。Boss/狂暴状态指示保留在顶部栏右侧区域。

#### Scenario: 普通关卡状态栏
- **WHEN** 玩家处于普通关卡（非 Boss）
- **THEN** 顶部栏居中显示"关卡: N"和"回合: X/20"，无额外文字

#### Scenario: Boss 关卡状态栏
- **WHEN** 玩家处于 Boss 关卡
- **THEN** 顶部栏居中显示关卡和回合号，右侧显示 Boss 徽章或狂暴提示

### Requirement: 英雄面板网格属性展示
英雄状态面板中的属性 MUST 使用 2×2 网格布局展示，标题居中且使用绿色区分。每个属性带 emoji 图标。

#### Scenario: 英雄属性展示
- **WHEN** 英雄状态面板渲染
- **THEN** 显示"英雄"标题（绿色，居中），HP 条下方为 2×2 网格：物攻/魔攻/防御/暴击

### Requirement: 怪兽面板网格属性与技能标签
怪兽状态面板中的属性 MUST 使用 2×2 网格布局展示，标题居中且使用红色区分。技能以彩色标签形式展示。元素克制信息整合到属性网格中。

#### Scenario: 怪兽属性与技能展示
- **WHEN** 怪兽状态面板渲染
- **THEN** 显示"怪兽 元素名"标题（红色，居中），HP 条下方为 2×2 网格（物攻/魔攻/防御/元素），技能以彩色标签横向排列

### Requirement: 操作按钮底部横条
保存和回主菜单按钮 MUST 放置在一个横条容器中，该容器位于左侧面板最底部，宽度与左侧面板一致，背景色半透明。

#### Scenario: 操作按钮底部对齐
- **WHEN** 战斗页面渲染
- **THEN** 左侧面板底部有一个横条区域，包含"保存"和"回主菜单"按钮，横条宽度与左侧面板一致
