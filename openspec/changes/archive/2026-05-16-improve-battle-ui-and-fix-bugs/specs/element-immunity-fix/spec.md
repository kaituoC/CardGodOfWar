## ADDED Requirements

### Requirement: 元素免疫技能在伤害计算中生效
当怪兽触发元素免疫技能时，对应元素的攻击 MUST 不受元素克制/被克关系影响（元素倍率为 1.0），但仍受防御、暴击等其他计算影响。

#### Scenario: 免疫元素攻击时倍率为中性
- **WHEN** 怪兽触发元素免疫技能（如免疫火元素）且英雄使用火元素卡牌攻击
- **THEN** 元素倍率为 1.0，伤害按基础攻击×系数-防御计算，不受克制/被克影响

#### Scenario: 非免疫元素攻击时正常计算
- **WHEN** 怪兽触发元素免疫技能（如免疫火元素）但英雄使用非火元素卡牌攻击
- **THEN** 正常计算元素克制/被克倍率

#### Scenario: 未触发元素免疫技能时
- **WHEN** 怪兽拥有元素免疫技能但本回合未触发（随机判定失败）
- **THEN** 所有元素攻击正常计算克制/被克倍率
