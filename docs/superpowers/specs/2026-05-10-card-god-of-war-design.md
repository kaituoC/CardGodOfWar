# 《卡牌战神》(Card God Of War) 游戏设计文档

## 一、游戏概述

- **游戏名称**：卡牌战神 (Card God Of War)
- **游戏类型**：单机卡牌策略闯关游戏
- **目标用户**：休闲娱乐玩家
- **核心体验**：随机抽卡、策略选择、元素克制、角色成长
- **技术栈**：Electron + Vue

### 核心玩法循环

```
关卡挑战 → 胜利获得属性成长 → 抽取新卡牌 → 挑战更高难度关卡
```

## 二、角色系统

### 2.1 英雄（玩家控制）

| 属性 | 初始值 | 胜利后成长 |
|------|--------|-----------|
| 物理攻击 | 10 | +1 |
| 魔法攻击 | 10 | +1 |
| 防御 | 5 | +1 |
| 最大血量 | 100 | +3 |
| 暴击率 | 0% | +1%（上限100%） |
| 当前血量 | 满值 | 不变（继承上一关结束时的剩余血量） |

- 英雄每关开始时的血量 = 上一关结束时的剩余血量
- 物理攻击造成 `物理攻击 × 系数` 的伤害
- 魔法攻击造成 `魔法攻击 × 系数` 的伤害
- 恢复卡牌恢复 `最大血量 × 系数` 的血量

### 2.2 怪兽（电脑生成）

| 属性 | 第1关初始值 | 每关成长 |
|------|-----------|---------|
| 物理攻击 | 8 | +5 |
| 魔法攻击 | 8 | +5 |
| 防御 | 3 | +4 |
| 最大血量 | `50 × (关卡数 ^ 1.3)` | 按公式递增 |
| 暴击率 | 5% | +1%（上限100%） |
| 元素属性 | 火/雷/水 随机分配 | 固定不变 |
| 特殊技能 | 普通怪兽1个，Boss 2个 | 固定不变 |

- 每关开始时怪兽满血
- 第 N 关怪兽血量计算公式：`基础血量 × N^1.3`
- 第1关怪兽血量 = 50

## 三、元素系统

### 3.1 元素克制关系

```
火 → 雷 → 水 → 火
（箭头表示克制方向，克制方攻击被克制方时伤害加成）
```

### 3.2 元素归属

- **英雄无元素属性**
- **卡牌有元素属性**（物理/魔法攻击卡都带有火/雷/水元素标识）
- **怪兽有元素属性**（每只怪兽固定一个元素）
- 元素克制 = **卡牌的元素** vs **怪兽的元素**

### 3.3 伤害倍率

| 攻击方（卡牌元素） | 被攻击方（怪兽元素） | 伤害倍率 |
|-----------------|-----------------|---------|
| 火 | 雷 | ×1.5 |
| 雷 | 水 | ×1.5 |
| 水 | 火 | ×1.5 |
| 火 | 水 | ×0.5 |
| 雷 | 火 | ×0.5 |
| 水 | 雷 | ×0.5 |
| 同元素 | 同元素 | ×1.0 |

## 四、卡牌系统

### 4.1 卡牌类型与比例

| 卡牌类型 | 数量比例 | 说明 |
|---------|---------|------|
| 物理攻击卡 | 10 | 造成物理攻击 × 系数 的伤害 |
| 魔法攻击卡 | 10 | 造成魔法攻击 × 系数 的伤害，附带元素属性 |
| 血量恢复卡 | 8 | 恢复最大血量 × 系数 的血量 |
| 属性提升卡 | 6 | 永久提升英雄某项属性 |

### 4.2 卡牌星级与系数

| 星级 | 出现比例 | 物理攻击系数 | 魔法攻击系数 | 恢复系数 |
|------|---------|-------------|-------------|---------|
| 1星 | 6 | ×1.0~×1.5 | ×1.0~×1.5 | ×0.3~×0.4 |
| 2星 | 3 | ×1.5~×2.2 | ×1.5~×2.2 | ×0.4~×0.6 |
| 3星 | 1 | ×2.2~×3.0 | ×2.2~×3.0 | ×0.6~×0.8 |

### 4.3 属性提升卡牌

| 提升属性 | 提升值（1星/2星/3星） |
|---------|---------------------|
| 物理攻击 | +1 / +2 / +3 |
| 魔法攻击 | +1 / +2 / +3 |
| 防御 | +1 / +2 / +3 |
| 最大血量 | +5 / +8 / +12 |
| 暴击率 | +2% / +3% / +5% |

### 4.4 抽卡机制

- 每回合开始时，从卡牌池中随机抽取3张卡牌供玩家选择
- 玩家选择一张卡牌后，其他两张消失
- 卡牌星级随机比例：1星:2星:3星 = 6:3:1
- 每回合只能使用一张卡牌

## 五、战斗系统

### 5.1 回合流程

```
1. 回合开始（最多20回合）
2. 随机生成3张卡牌
3. 玩家选择一张卡牌并执行效果
4. 英雄攻击怪兽（若使用攻击卡）/ 恢复或提升属性
5. 怪兽攻击英雄（使用物理/魔法攻击或特殊技能）
6. 判定胜负
   - 怪兽血量 ≤ 0 → 英雄胜利，进入下一关
   - 英雄血量 ≤ 0 → 英雄失败，弹出提示
```

### 5.2 伤害计算

```
最终伤害 = (攻击方攻击力 × 卡牌系数 - 防御方防御) × 元素倍率 × 暴击倍率
最低伤害为1（攻击不可能无效）

暴击倍率 = 1.5（暴击时）
暴击判定：随机数 < 暴击率 → 暴击
```

### 5.3 怪兽特殊技能

普通怪兽拥有1个技能，Boss拥有2个技能。

| 技能 | 效果 |
|------|------|
| 护盾 | 本回合受到伤害减少50% |
| 吸血 | 本回合造成伤害的30%恢复自身血量 |
| 暴击强化 | 本回合暴击伤害变为×2.0 |
| 元素免疫 | 本回合完全免疫某一元素攻击 |
| 眩晕 | 下一回合英雄无法使用攻击卡牌（只能用恢复/属性提升卡） |

## 六、Boss关卡

### 6.1 Boss特性

- **触发条件**：每第5关（关卡5、10、15...）
- **2个特殊技能**（普通怪兽只有1个）
- **血量更高**：Boss血量 = `100 × (关卡数 ^ 1.3)`
- **简化狂暴机制**：超过15回合未击杀Boss，之后每回合Boss伤害 +20%

### 6.2 Boss狂暴

```
if (当前回合 > 15) {
    狂暴倍率 = 1 + (当前回合 - 15) × 0.2
    Boss实际伤害 = Boss基础伤害 × 狂暴倍率
}
```

## 七、关卡与胜利条件

### 7.1 胜利条件

- 怪兽血量 ≤ 0，英雄胜利
- 进入下一关，英雄获得属性成长
- 当前血量不变（继承剩余血量）

### 7.2 失败条件

- 英雄血量 ≤ 0，英雄失败
- 弹出提示："挑战失败"
- 选项：
  1. **重新挑战本关**（保持当前属性，血量恢复为失败时的血量）
  2. **返回第一关**（所有属性重置为初始值）

## 八、页面布局

### 8.1 布局要求

- 战斗记录在卡牌选择区域的**右侧**，防止上下高度超过屏幕
- 战斗记录显示**具体计算过程**（如：`物理攻击 10 × 系数 1.5 = 15，防御 3 减免后 = 12，暴击 ×1.5 = 18`）
- 最新战斗记录在**最下方**，自动滚动
- 所有内容在**一屏内展示**，无滚动条，避免页面抖动

### 8.2 主界面布局

```
+--------------------------------------------------+
|           卡牌战神  Card God Of War              |
+--------------------------------------------------+
|                                                  |
|              [  新游戏  ]                         |
|                                                  |
|              [  继续游戏  ]  ← 有自动存档时显示   |
|                                                  |
+--------------------------------------------------+
|  手动存档槽位                                     |
+--------------------------------------------------+
|  存档1: 关卡7  HP 62/112  [加载]  [覆盖保存]      |
|  存档2: 关卡3  HP 100/100 [加载]  [覆盖保存]      |
|  存档3: 空                                        |
+--------------------------------------------------+
```

### 8.3 战斗页面布局

```
+--------------------------------------------------------------+
|  全局状态栏                                                   |
|  关卡: 7  |  回合: 12/20  |  Boss战(狂暴警告!)  |  怪兽元素: 雷(火克之)  |
+--------------------------------------------------------------+
|  英雄状态栏           |  怪兽状态栏                            |
|  HP ████████░░ 80/100 |  HP ████░░░░░░ 150/350               |
|  物攻:12 魔攻:12 防:8 |  物攻:38 魔攻:38 防:19 元素:雷       |
|                       |  技能: 护盾, 吸血                     |
+-----------------------+--------------------------------------+
|  卡牌选择区           |  战斗记录                              |
|                       |  [自动滚动至最下]                     |
|  [卡牌1][卡牌2][卡牌3]|                                      |
|                       |  - T12: 英雄物理 12×1.5=18, 雷克火   |
|                       |    ×1.5=27, 防御19减免后=8           |
|                       |  - T12: 怪兽反击, 38-8=30伤害        |
|                       |  - T11: ...                           |
+-----------------------+                                      |
|  [保存]  [回主菜单]     |                                      |
+-----------------------+--------------------------------------+
```

**按钮位置**：卡牌选择区域下方，低调小按钮，不干扰战斗体验。
- `[保存]` — 点击后弹出存档槽位选择（1/2/3），选择后覆盖保存
- `[回主菜单]` — 点击确认弹窗"返回主菜单？当前进度将丢失（自动存档除外）"

**战斗页面中无存档相关入口**，避免干扰战斗体验。存档操作仅在主界面进行。

## 十一、存档系统

### 11.1 存档内容

| 数据项 | 说明 |
|-------|------|
| 当前关卡 | 第几关 |
| 英雄属性 | 物理攻击、魔法攻击、防御、最大血量、暴击率 |
| 英雄当前血量 | 存档时的血量 |
| 关卡进度 | 当前回合数 |
| 怪兽信息 | 当前怪兽的属性、技能、元素、剩余血量 |

### 11.2 自动存档

- 每回合结束后自动保存到本地
- 存档文件路径：`~/.cardgodofwar/saves/auto-save.json`
- 游戏启动时检测自动存档，提示"检测到未完成的进度，是否继续？"

### 11.3 手动存档

- 主界面提供"保存进度"按钮
- 支持最多3个手动存档槽位
- 存档文件路径：`~/.cardgodofwar/saves/manual-save-{1,2,3}.json`

### 11.4 加载存档

- 主界面提供"加载存档"入口，显示3个手动存档槽位的摘要信息（关卡数、英雄血量）
- 选择存档后恢复游戏状态

### 11.5 新游戏

- 主界面"新游戏"按钮清除所有状态，从第1关重新开始
- 确认弹窗："开始新游戏将清除当前进度，是否继续？"

## 十二、技术架构概要

### 10.1 项目结构

```
CardGodOfWar/
├── src/
│   ├── main/          # Electron主进程
│   ├── renderer/      # Vue渲染进程
│   │   ├── components/
│   │   ├── views/
│   │   ├── stores/    # Pinia状态管理
│   │   └── assets/    # 图片、样式
│   └── shared/        # 游戏逻辑（可复用）
├── docs/
│   └── superpowers/specs/
│       └── 2026-05-10-card-god-of-war-design.md
└── package.json
```

### 10.2 核心模块

| 模块 | 职责 |
|------|------|
| GameEngine | 回合管理、胜负判定、关卡推进 |
| CardPool | 卡牌生成、随机抽卡、星级分布 |
| BattleCalculator | 伤害计算、元素克制、暴击判定 |
| MonsterGenerator | 怪兽属性生成、技能分配 |
| StateManager | 英雄/怪兽状态、血量管理 |
